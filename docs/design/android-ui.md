# Clash Android 页面设计草案

日期：2026-10-23。依据当前 Clash-Manager README、docs/user-guide.md、web/src/pages 与 tokens.css；当前 Android 工作目录尚无应用源码。本轮交付是 UI 设计，不是已运行的 Android 应用。

设计进展：用户已选择第2组风格。完整二级页浅色/深色画板见 [二级页面设计集](secondary/README.md)，主题和交互规范见 [主题与状态](secondary/theme-and-states.md)。原始三组图保留作探索记录，不再作为待选择方案。

## 产品边界

默认设计为免 Root 的 Android 本机 Mihomo 客户端，继承现有项目完整配置管理能力。以 Android VPN 服务承载流量接管。已有远程/外部 Core 作为可选高级管理模式保留，必须明确区分“本机 VPN”和“远程内核”；连接远程控制器不会自动代理手机流量。

一级导航：首页、代理、配置、活动、设置。二级页面采用返回导航，编辑器独占屏幕；简单选择使用底部弹层，不在弹层内嵌套复杂编辑器。

## 页面清单与 UI 规格

| 页面 | 入口与布局 | 操作与反馈 |
| --- | --- | --- |
| 01 首次使用 | 简短说明 → 导入配置 → 检查配置 → 启动 VPN；主按钮固定底部 | 支持跳过导入浏览；启动时才请求系统 VPN 授权；拒绝后保留配置并可重试 |
| 02 首页 | 顶部应用名；连接状态与启停；规则/全局/直连；当前节点、当前配置；实时上下行及小型图表；出口检测 | 节点行进入选择；配置行进入详情；连接数进入连接列表；出口检测主动触发；VPN启动不等于网络检测通过 |
| 03 代理节点 | 顶部搜索；代理组选择；排序和测速；节点单行显示名称、协议、延迟、选中状态 | 切换立即反馈；区分未测试、测试中、超时、正常；测试时可取消；自动组显示当前选中节点并提供策略说明 |
| 04 代理组详情 | 组名、类型、当前节点；成员列表；测试信息 | 编辑自定义组；原始组修改写入订阅增强；处理空组和引用循环错误 |
| 05 节点编辑 | 名称/类型/服务器/端口为基本字段；认证与传输参数按协议展开 | 密码默认遮蔽；保存草稿或保存并应用；删除原始节点表现为排除，可恢复 |
| 06 代理组编辑 | 名称、策略类型、成员多选与顺序；高级健康检查参数折叠 | 搜索成员、拖动排序，并提供上下移动替代操作；保存前检查引用和循环 |
| 07 配置列表 | 当前配置突出标记；其他订阅/本地文件列表；流量和到期信息；添加按钮 | 更新和应用是独立动作；每份配置有管理菜单；缺少配额时显示未提供而不是0 |
| 08 添加/导入配置 | 链接、文件、粘贴三种方式；可选扫码辅助；预览名称和格式 | 文件使用系统选择器；先校验再保存或应用；链接默认隐藏敏感参数；失败保留输入 |
| 09 订阅详情 | 名称和状态摘要；流量、到期、最近下载/应用时间；信息、规则、节点、代理组、覆写、脚本、YAML入口 | 更新进度、错误原因、重试；明确增强作用于当前订阅；删除需要确认 |
| 10 订阅信息编辑 | 名称、地址、更新间隔、自动更新、当前配置更新后自动应用 | URL修改不自动下载；显示计划更新与最近实际执行时间，避免承诺后台严格定时 |
| 11 规则列表 | 当前配置提示；规则/规则集切换；搜索、类型/策略/来源筛选；紧凑列表 | 单条显示类型、内容、策略和启用开关；能力不支持时解释原因；长文本进入详情 |
| 12 规则编辑 | 类型选择、内容、目标策略、前置/后置；原始/自定义来源；底部保存栏 | 保留现有全部规则类型；排除/恢复原始项；自定义增删排序；批量操作明确作用于筛选结果；显示未保存标记 |
| 13 规则集导入预览 | 文件/链接/文本 → 识别 → 预览 → 保存；预览含数量、格式、策略、冲突和警告 | 保留现有格式支持；前置/后置/替换合并；错误阻止保存；警告明确确认；支持保存到订阅或保存并应用 |
| 14 规则集详情 | 来源、格式、条目数、更新时间、更新间隔；内容搜索 | 单个更新、全部更新；显示失败原因；大列表分页或虚拟滚动 |
| 15 覆写编辑 | 标题显示全局/订阅范围；启用开关；YAML编辑；合并顺序说明 | 校验、保存、保存并应用；查看最终合并结果；重置先提示作用范围 |
| 16 脚本编辑 | 全局/订阅范围；代码编辑器、说明、执行结果面板 | 保留现有扩展脚本语义；Android执行环境另行验证；失败显示定位与日志，不静默忽略 |
| 17 配置文件/YAML | 原始配置/最终生效配置切换；行号、搜索、语法高亮；底部校验和保存栏 | 生效结果只读；编辑对应源文件；校验错误可跳转；离开未保存内容时提示 |
| 18 配置历史 | 时间、来源、变更摘要；点击查看差异 | 备份、导出、恢复预览；恢复后校验再应用；失败不覆盖上次可用配置 |
| 19 活动·连接 | 连接/日志标签；搜索域名/IP/应用；筛选TCP/UDP及策略；实时连接列表 | 暂停刷新、按流量/时长排序；关闭单条/筛选结果/全部；批量关闭确认数量 |
| 20 连接详情 | 域名/IP与端口、协议、应用、开始时间、上下行、命中规则、完整代理链 | 复制字段、关闭连接、以当前域名预填规则；应用归属不可得时显示未知，不猜测 |
| 21 活动·日志 | 等级筛选、搜索、时间戳日志；暂停和跟随滚动；导出菜单 | 分清内核日志与应用启动日志；设置保留时长/大小；分享前隐藏订阅凭据等敏感信息 |
| 22 设置总页 | VPN与分应用、网络与端口、DNS与解析、路由规则、内核与GEO、自动化、外观与语言、备份与恢复、关于与更新 | 每行有当前摘要；高级内容进入独立页，不把全部表单塞在一个长页面 |
| 23 VPN设置 | 服务状态、授权状态；IPv4/IPv6路由、MTU、局域网绕过、排除网段；高级参数折叠 | 始终开启VPN和阻止无VPN连接提供系统设置入口；明确更改哪些选项需要重建连接 |
| 24 分应用代理 | 全部应用/仅选中应用/排除选中应用；应用搜索、图标、名称、包名、多选 | 显示已选数量；系统应用筛选；仅选中与排除互斥；保存后必要时提示重连；不可枚举的应用有说明 |
| 25 网络与端口 | Mixed/HTTP/SOCKS端口开关和输入；监听范围、局域网访问、认证、IPv6和延迟选项 | 即时检查端口冲突；局域网开启后展示实际监听地址；外部设备需手工配代理；不承诺热点自动转发 |
| 26 DNS基础 | 启用、解析模式、监听、Fake IP范围；当前生效来源 | 配置与全局覆写关系清晰；修改后校验；必要时重建VPN并提示 |
| 27 DNS服务器 | 默认、主解析、回退、代理节点、直连五组列表 | 增删排序；支持对应内核格式；长地址折行；无效地址定位到行 |
| 28 Fake IP与域名策略 | 过滤模式、域名过滤、域名策略列表 | 搜索、添加、编辑、批量粘贴；说明匹配效果；避免必须手写整份YAML |
| 29 DNS回退与Hosts | 回退过滤和Hosts分别进入子页；条件列表/域名地址映射列表 | 添加编辑删除、校验、空状态示例；高级YAML入口保留 |
| 30 内核管理 | 版本、运行状态、架构；重启/重载；日志等级、连接和延迟测试参数 | 本机使用Android适配内核；内核升级入口依分发和构建能力提供，不能照搬Linux下载替换可执行文件 |
| 31 GEO数据 | GeoIP/GeoSite/MMDB/ASN等当前实际支持项列表；来源、更新时间和大小 | 单项/全部更新、自动更新、失败重试；不展示内核不支持的虚构项 |
| 32 自动化与后台运行 | 订阅/GEO更新计划、启动行为、系统始终开启VPN入口、后台限制状态 | 显示最近执行结果；后台调度受Android限制；不承诺精确分钟级任务或永久保活 |
| 33 外观与语言 | 跟随系统/浅色/深色；中文/English；应用图标选择（实现支持时） | 即时预览；保留用户节点名称与原始日志；支持字体缩放与减少动画 |
| 34 备份与恢复 | 导出范围：配置、增强、偏好；备份清单；恢复预览 | 提醒备份可能含订阅和凭据；系统文件选择器；验证格式/版本后恢复，报告失败项 |
| 35 关于与更新 | 应用版本、内核版本、更新记录、开源许可、问题反馈 | 更新方式依安装渠道；诊断导出有脱敏预览；不沿用示例图中的桌面版本号 |
| 36 远程控制器（高级） | 本机/远程明确标识；实例列表、地址、认证、连接测试 | 凭据遮蔽；根据对端能力显示更新/重启/规则操作；远程不支持的操作给出原因；不得把远程已连接显示成本机VPN开启 |

## 状态与交互

- 启动状态：未配置、未授权、启动中、VPN已启动、停止中、失败。连通性单独显示未检测/检测中/通过/失败；不能用绿色运行指示代替网络可用证明。
- 编辑状态：未修改、草稿、校验中、校验失败、正在应用、应用成功、应用失败。失败保留草稿和上次可用配置。
- 切换配置：下载→合并增强→校验→加载→核对结果；在流程完成前不得把新配置标记为当前生效。
- 关键更改说明影响：是否重建VPN、是否断开连接、是否覆盖增强。删除和恢复等有破坏性的操作确认具体对象。
- 断网、无节点、空日志、订阅过期、更新失败都有就地说明和可执行下一步，不仅弹出瞬时提示。
- 常驻通知提供状态、速率、停止和打开应用；可提供系统快捷设置磁贴。通知权限和VPN授权是不同流程。

## Android 适配矩阵

| 现有功能 | 设计处理 |
| --- | --- |
| 节点、代理组、订阅、规则、覆写、脚本、YAML | 保留入口与能力；脚本运行时和内核API兼容性在实现时验证 |
| Linux TUN/自动路由 | 转成Android VPN与路由配置，不暴露无效的Linux接口/路由命令 |
| fnOS系统代理/Shell环境变量 | 本机版移除；普通Android应用不能用此方式控制其他应用环境变量 |
| NAS目录扫描 | 改成系统文件选择器与显式授权访问，不扫描NAS路径 |
| 旁路由、iptables/nftables、宿主转发 | 不作为免Root默认功能；将来Root扩展另行设计，不显示假开关 |
| 热点设备代理 | 保留显式HTTP/SOCKS接入；不将本机VPN等同于热点透明代理 |
| 管理登录 | 本机无需强制账户；远程控制器保留认证 |
| Core更新 | 保留版本与更新体验；具体更新机制需按Android应用构建/安装渠道确定 |
| FPK/DEB/Docker更新 | 改成Android应用更新与渠道信息 |
| fnOS主题/窗口事件 | 改成Android系统主题、返回行为与边到边布局 |

Android官方说明：同一用户/资料同一时间只有一个活动VPN服务，支持按应用VPN与始终开启VPN；首次连接需要系统授权。参考：https://developer.android.com/develop/connectivity/vpn 。自动化与权限具体实现需按目标Android版本再次验证。

## 视觉规范与效果稿

- 延续现有蓝色强调色和中性表面。浅/深色两套主题；正文14–16sp、主标题22–26sp，主要点击区至少48dp。
- 手机按390×844逻辑视口设计；内容边距16dp；基础间距8/12/16/24dp；表单单列；长列表使用轻分割线。
- 只用颜色区分状态不够，必须同时有文字或图标；长节点名可换行；延迟保留右侧位置；字体放大后布局可增长。
- 三张图是主页面布局探索，各自包含五个一级页面。已选第2组；二级页面对应画板见 secondary/README.md，功能含义以本规格及补充主题规范为准。
- 图中数据、版本、应用归属均为示例。生成图出现“系统代理”时，安卓正式文案应改为“VPN接管”；不添加桌面环境变量功能。规则/全局/直连属于转发策略，不能和VPN接入开关混为一谈。
- 图一：连接优先。图二：节点优先。图三：紧凑监控。深色方案不是独占功能，所有方向均应支持浅/深主题。

## 后续验证重点

当前没有运行中的Android应用，因此这些图不是实机验证结果。实现后需在设备/模拟器验证VPN授权拒绝与重试、订阅导入应用、切换节点与规则模式、按应用代理、网络切换和后台恢复、错误配置保留、长文本和大字体、暗色模式与系统返回。
