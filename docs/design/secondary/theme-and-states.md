主题选项：跟随系统、浅色、深色。默认跟随系统；用户显式选择后保留。所有页面、弹层、代码编辑器、图表、提示条、空状态、键盘上方工具条同步切换。主题切换保留导航位置、草稿、搜索和滚动位置，不重启VPN。不同主题不改变页面结构和业务含义。

## 布局

- 手机逻辑视口390×844，真正实现按可用宽高自适应，尊重系统安全区。
- 二级页56dp标题栏：返回、标题、可选单一操作。编辑状态显示“未保存”。无五栏底部主导航。
- 内容边距16dp，垂直节奏8/12/16/24dp，单行列表至少56dp，双行至少72dp；所有操作热区至少48dp。
- 标题22sp，正文16sp，辅助14sp，代码14sp等宽。字体放大时允许换行和内容增高。
- 表单操作区固定底部，横排“保存草稿”“保存并应用”；键盘打开时操作区置于键盘上方或随表单滚动，不遮挡焦点。
- 长列表不使用层层卡片；分组采用标题、轻分割和少量背景变化。短选择用底部弹层，节点/规则/YAML编辑使用完整页面。
- 原始内容与增强内容有明确来源标签，禁止将订阅原始项的排除伪装成永久删除。

## 功能状态

| 状态 | 表现 | 下一步 |
|---|---|---|
| 没有配置 | 图标、简短说明、导入按钮 | 导入后校验 |
| VPN未授权 | 中性说明，不显示已连接 | 点击启动后调用系统授权 |
| VPN被拒绝 | 原页提示、保留配置 | 重试或稍后 |
| 更新失败 | 错误时间、原因、旧配置仍可用 | 重试 |
| 校验失败 | 字段/行号错误与底部摘要 | 定位修改，禁止应用 |
| 正在应用 | 明确进度，禁止重复提交 | 成功才更新当前配置标记 |
| 应用失败 | 保留草稿，说明仍使用的旧配置 | 查看日志或重试 |
| 未保存返回 | 保存草稿/放弃/继续编辑三种选择 | 保留清晰授权边界 |
| 远程不支持 | 控件禁用并解释对端能力 | 不伪造开关 |
| 清空/删除/恢复 | 对象名、数量与影响说明 | 取消或明确确认 |

错误不能只靠颜色表达。禁用状态仍保留可读原因。加载状态不清空已显示的数据；动态测速结果保留节点位置，除非用户明确选择实时重排。应用归属不可得时写“未知应用”，不能根据域名推断应用。

## 重点交互

- 订阅信息保存、订阅下载、配置应用是三个动作；修改链接后不自动下载或切换。
- 规则开关、增强编辑区和导入预览分别呈现即时操作、草稿和待确认结果，避免混淆。
- 覆写/脚本始终显示“全局”或具体订阅名；合并顺序沿用现有项目，不能从图稿推断新的优先级。
- VPN路由和分应用更改可能重建连接，按钮使用“保存并重连”并提前说明。
- 始终开启VPN、无VPN阻断、电池优化使用系统设置入口，不绘制成应用可以直接控制的普通开关。
- 本机与远程控制器明显区分；远程连接成功只代表管理API可达。
- 备份包含凭据时显式说明；诊断导出必须先显示实际脱敏预览，“不包含原始凭据”是实现验收要求而非静态稿的证明。
