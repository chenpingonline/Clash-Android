# 素白主题

视觉基准：[用户选定的紧凑版](reference.png)。主题 ID 为 `plain`，中文名「素白」，英文名 Plain white。

- 中性灰背景 `#F4F4F4`、纯白分组表面、20dp 圆角、页面左右 16dp、组间 12dp。
- 正文 14sp，辅助文字 12sp，页面标题 20sp，彩色图标底块 32dp，单行设置项至少 54dp。
- 底栏保持五个入口，项目图标 19dp，文字 10sp，触控项至少 48dp；全局字体缩放继续生效。
- 连接、当前配置/节点、测速和统计均由真实状态驱动，效果图中的节点和速率不写入应用。
- 路由规则、远程控制保留在设置高级分组；代理的协议筛选、排序、节点/组编辑收进“筛选与排序”。

效果图由内置 ImageGen 基于原参考图生成，并按用户反馈缩小字号、图标与卡片高度。实现采用现有 Compose Material 图标库。验证见 `docs/qa/plain-theme/`。
