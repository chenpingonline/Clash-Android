# 可折叠代理组与双列节点验证

日期：2026-10-24。视觉目标：[确认的设计](../../design/proxy-accordion/reference.png)。

实现：独立圆角组头（12dp）、两侧12dp留边、收起组间10dp留白；展开组后显示双列节点，节点圆角10dp，列间距8dp。多个组可独立展开或收起；收起后仍显示当前成员。统一普通与素白代理页，主题颜色沿用现有色板。

节点卡片显示名称、协议、延迟和选中状态；手动组可选择成员，自动组只读。大字体（>=1.3倍）或窄屏（<360dp）改用单列，组内测速操作换行，避免挤压长组名。

顶部提供搜索、一键测速、更多菜单；菜单内保留协议筛选、原始/名称/延迟排序、编辑节点和编辑代理组。一键测速对当前筛选匹配的实际节点去重，排除代理组入口及 REJECT/REJECT-DROP/PASS；组内测速按该组匹配成员执行。最多并发4个，支持停止；失败保留文字反馈，不自动切换当前节点。

## 验证证据

- [设计与运行对照](comparison.png)、[局部细节](detail.png)：左右同屏核对圆角、留白、双列卡片与选中状态。运行样本为本地 direct 节点；名称不代表远端服务器或外网延迟。
- [真实页面](live.png)、[同时展开两组](live-two-expanded.png)：390×844dp Android 16 模拟器，系统栏和现有浮动底栏由应用/系统正常绘制。
- [大字体深色](large-dark.png)：组件测试，长组名与英文1.5倍字体。
- Computer Use 在本地实时模拟器镜像中进入代理页，收起 AI、展开 TELEGRAM、选择 JP 01、测试 HK 02，并重新展开 AI。节点选择同步到组头；测试其他节点未改变 JP 01 的选中状态；两组可同时展开。
- ProxyLayoutTest 4项：独立展开收起、组头间距、双列位置、大字单列、自动组只读、搜索/协议限制测速范围、批量去重、并发上限、失败和取消。
- ProxyRuntimeTest 1项：真实 Mihomo 内核下切换成员、组内测速、一键测速对共享节点及 GLOBAL 去重。HTTP 204 来自设备内 MockWebServer，没有依赖外网服务。
- PlainThemeTest 2项：素白主题配置、VPN启动/停止、DIRECT/REJECT切换、搜索、主题恢复、大字号等回归。
- 单元测试11项、设备测试7项、lint、debug 构建全部通过，见 [构建记录](validation.log)。

## 说明

设备测试初轮遇到测试准备状态、组选取以及预期计数问题，已修正测试：显式准备VPN授权、按组展开状态定位、区分实际成员与代理组入口。一键测速排除代理组入口的修复已包含在最终版本。手动验证改用不接管Compose测试时钟的普通Activity宿主，避免测试冻结时钟干扰外部点击；最终正常测试不含手动等待。

这是模拟器和本地内核验证，未建立真实订阅节点、真机、厂商系统及公网连接的验证结论。
