# 手动订阅连接诊断

2026-10-24，0.2.6-dev，Android 16 / Pixel 9 Pro arm64模拟器。

## 行为

- 在链接导入及订阅信息页点击“开始对比”，顺序发送当前、CFA和CMFA身份的GET请求，相同UA只请求一次。
- 复用订阅下载的HttpURLConnection、HTTPS约束、手动重定向、跳转循环及上限检查；到最终响应头即断开，不读取完整配置、不保存配额或错误下载记录。
- 展示最终HTTP状态、单调时钟测量的响应耗时及跳转次数；网络/不安全跳转等失败无最终状态，显示固定安全提示。耗时包含DNS、TLS、重定向；缓存、连接复用及网络波动会影响结果。
- 每种身份最多30秒，无自动重试；支持取消。编辑地址/UA或离开页面会取消当前任务，清除不再适用的结果。
- 仅HTTP 2xx结果提供身份选择。选择只修改表单，仍需“保存配置”或“保存订阅信息”才持久生效；不校验或替换YAML。诊断结果只保留在当前页面，不写入日志或备份。
