# 订阅整体超时与失败保护

2026-10-24，0.2.6-dev，本地Android 16 Pixel 9 Pro arm64模拟器。

## 行为

- 完整订阅下载统一60秒预算，包含DNS、连接/TLS、所有跳转、响应头、响应正文和一次有限重试的500ms退避。既有15秒连接、20秒单次读取上限继续保留，但不会在每一跳或重试时重置整体预算。
- 超时或调用者取消时关闭当前连接；慢速持续返回正文也受60秒预算约束。调用者取消向上传递，不写入部分配置或配额。
- 临时网络错误及502/503/504最多重试一次。403以及401/404/410/429/500等不自动重试；证书、协议错误及大小/配置校验错误不重试。有限重试沿用原UA，所有尝试共用60秒预算。
- 收到完整且不超过8MiB的正文后才返回；长度已知时检查完整性。配置经内核校验后才原子替换；活动配置更新须校验后暂存。失败时保留原配置、历史及已存在的有效暂存更新。
- 后台记录最近尝试时间，失败后同样按配置更新周期等待，避免每15分钟重复请求失败订阅；手动更新忽略周期限制。403在Worker本轮计为失败，不返回WorkManager重试。
- 手动连接诊断继续保持每种身份30秒、不重试、只测试响应头。

## 验证

- SubscriptionProtectionTest覆盖真实60秒生产预算：前两跳各延迟12秒，再每5秒返回1字节，单次读取始终未超20秒；断言约60秒失败、总3个请求、原始配置/持久化快照/历史/暂存更新及上次成功时间均未替换，未保存配额。
- 后台403只请求一次，下一轮Worker不立即请求；用户主动更新仍可恢复。
- 503后成功最多两次请求；连续502/504仅两次；鉴权等失败不重试，非法YAML及运行中非法更新保留原数据。
- 取消慢正文读取不保存配额或错误记录、不开始第二次请求。
- 正文中途断开时不保存部分内容，协议错误不重试，其余可重试网络错误最多重试一次。
- gzip正常下载及解压后超过8MiB拒绝通过；长度检查没有误将压缩长度当作解压长度。
- 本次变更为下载与调度逻辑，没有新增界面流程。

JDK17构建通过，11项单元测试、14项不同的设备测试通过（首次联合执行12项，随后单独执行中断正文和gzip两项），lintDebug通过。实际60秒测试包含在上述设备测试中。

本地APK通过apksigner verify及zipalign -c -P 16 4，已同步dist产物与SHA-256。真实服务商及真机网络仍需独立验证；没有发布。
