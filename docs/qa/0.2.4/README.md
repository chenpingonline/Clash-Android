# 0.2.4-dev 页面样式统一

2026-10-24，Android 16 arm64 模拟器。延续 0.2.3 Dock 设计，将五个主入口与32个二级页面使用的公共组件统一到圆角、细边框、蓝色选中状态和一致的间距。

## 调整范围

- 卡片24dp圆角与细描边，导航行40dp浅蓝/深蓝图标底座，标题/说明/箭头对齐。
- 输入框统一16dp圆角与主题表面色；主按钮、提示卡、编辑器统一圆角与内边距。
- 设置开关放在卡片右侧，标签可换行；开关和复选框支持整行点击并保留对应无障碍角色。
- 分段选择提供选中语义；多操作按钮组允许换行，配置名称为状态标签预留空间。
- 深色主题补齐容器/边框色；上传色和VPN成功状态色改用主题色。

## 验证

- [页面回归原始记录](device.log)：32页 × 浅/深色 × 中文100%/英文150%，128张实际截图；另有无配置状态进入/返回遍历。两项页面测试通过。
- 同批编辑测试最初因旧断言把原VPN设置写死为空字符串而失败（原值实际为此前夹具的 `{}`）。改为验证非法输入不改变原值，没有修改产品保存逻辑；[修正后的编辑回归](editor.log)通过。
- 编辑回归覆盖代理组创建、规则 no-resolve 保留、端口保存/非法输入拒绝、非法MTU不覆盖原值，以及点击IPv6整行后保存状态。
- [主页面](main/)：使用 adb/UIAutomator 按实际 UI 树点击入口并截屏，检查浅深色导航选中状态。设备未暴露到 Computer Use 的应用列表，使用现有安卓设备工具完成验证。
- [二级页面截图](clash-uiqa/)为128张本轮产物；抽查VPN、网络设置、导入、编辑、备份等代表布局，不把截图遍历等同于所有外部功能联调。
- [构建/单元测试/Lint](build.log)、[签名](signature.log)、[16KiB zipalign](alignment.log)通过。
