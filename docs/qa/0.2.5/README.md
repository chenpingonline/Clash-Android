# 0.2.5-dev 轻量动效

2026-10-24，Android 16 arm64 模拟器。主要动画采用180–240ms的有限时长过渡，不增加循环动画或长弹跳。

## 实现

- 主入口按左右顺序短距离滑动/淡入；二级页面进入向前、返回反向。AnimatedContent使用目标页面渲染，不把退出内容错误绑定到新路由。
- Dock和忙碌进度条展开/收起；Scaffold继续为内容保留导航安全区。
- Dock图标选中缩放至1.08倍，图标/分段选择颜色平滑变化。
- 浅深色主题主要背景、表面、文字、边框和状态色使用220ms过渡。
- 重复进入当前页不重复压栈，退出页面的迟到导航点击不改变新页面。
- 使用Compose标准动画时钟，跟随系统animator_duration_scale；外观页同步说明。

## 验证

- [导航与编辑回归](navigation.log)：快速连续切换主入口、过渡中返回、再次进入/返回、主题切换；编辑保存和非法输入保护通过。
- [全页面与导航复查](pages.log)：3项通过，包含32个二级页面×浅深色×中文100%/英文150%，以及无配置页面进入/返回。
- [系统动画关闭](reduced-motion.log)：将模拟器animator_duration_scale设为0后导航测试通过，随后删除临时设置恢复原默认值。
- [实际操作录屏](motion-preview.mp4)：默认系统动画缩放下通过adb/UIAutomator实际点击主入口和VPN设置进入/返回，非生成示意动画。
- [构建/单元测试/Lint](build.log)、[APK签名](signature.log)通过，16KiB zipalign检查通过。

本轮没有进行真机帧率/功耗分析，模拟器测试不能证明所有厂商设备始终达到60/120fps。保留0.2.2 VPN修复，本轮没有重新验证公网代理或IPv6。
