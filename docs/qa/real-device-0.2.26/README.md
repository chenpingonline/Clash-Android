## 发现与限制

1. **远程表单错误提示不明确**：实例名称、HTTPS 地址与令牌均空时点“测试并保存”，显示 `Failed requirement.`，未指出字段。证据：56-remote-validation。
2. **规则导入错误文案暴露 JSON 结构**：显示 `错误：[{"message":"没有可识别的规则"}]` 及空对象；应转成用户可读的提示。证据：68-rule-validation。
3. **出口查询未成功**：当前配置下显示“获取失败”，可重试。单节点延迟与部分实际流量成功不能证明出口地理查询服务可达；未确定失败根因。证据：65-exit-after-40s。
4. 订阅中的流量、到期、客服等提示条目被提供为 Trojan 节点，一键测速显示失败。其余多个实际节点返回延迟；未把这些提示项失败归因为应用崩溃。
5. 小米镜像曾多次掉线并要求 Mac 解锁；第一次 VPN 服务后来停止，未确定是否用户操作、系统行为或应用原因。改用 USB 后完成一次明确的启动—运行—断开流程。
6. 深层保存、真实订阅更新、完整备份导出/恢复、远程实例联网、设备重启/长期后台、全部协议与全部节点未验证。本轮未覆盖用户配置的写入、恢复和删除。
7. 最后手机自动锁屏，代理组详情页面的补查未完成。结束时无法再次操作前台页面，不声称应用停在首页。
